这是一个非常核心的架构问题。在移动端处理 3 到 4 层的深度导航（首页 -> 大厅 -> 详情 -> 会话），最忌讳的就是让用户“迷路”或者感觉被困在一个深层页面里出不来。针对你描述的需求，我为你规划了“钻取式堆栈 (Drill-down Stack) + 抽屉/模态 (Modal)”的导航策略，并为你生成了 **Project 详情页 (Profile)** 的视觉 Mock-up。### 移动端导航层级安排建议：在移动端，我们需要通过**顶部状态栏的变换**和**转场动画**来明确层级，同时在深层级**释放屏幕空间**。1. **L0 (全局基座): 底部导航栏*** **可见性：** 仅在首页 (Welcome)、Project Hall、Agent Hub 等“大厅”层级显示。* **作用：** 在平行的大模块之间快速横跳。2. **L1 (大厅层): Project Hall*** **布局：** 顶部是标题（不需要返回键），中间是“新建项目”按钮、“项目列表”和“无归属会话列表”。底部是全局导航栏。* **动作：** 点击任意 Project，向左推入 L2 页面。3. **L2 (详情层): Project Profile (见下方设计图)*** **可见性：** **隐藏底部的全局导航栏**。因为用户进入单个 Project 后，心智已经聚焦于此，底部导航会分散注意力且占用空间。* **顶部：** 出现轻盈的 `< Projects` 返回按钮（支持 iOS 右滑返回手势）。* **内容：** 包含你提到的 Prompt、独立文件、工作目录入口、会话列表。4. **L3 (会话层): 通用 Chat Area*** **转场建议：** 既然 Chat Area 是通用的，建议在移动端不要用常规的“向左推入新页面”，而是采用**从下往上弹出的全屏毛玻璃面板 (Full-screen Bottom Sheet)**。* **优势：** 这样即使用户在 L3（聊天），他们在心理上也感觉自己仍然“身处这个 Project 之中”，点击左上角的`↓`，就能立刻落回到 L2   的项目面板，极大削减了层级过深的剥离感。---# 左上角：`AGENTS` 标题。右上角：`[ + ]` 新建 Standard/Superior Agent。* **[第一层级：G045 (The Prime)]*** **布局**：占据最显眼的顶部位置。卡片不需要明显的边界，而是用一圈极其微弱的、流动的 `#f8bf74` (高光色) 呼吸晕影包裹。* **头部**：特殊的六边形或带有古代符文装饰的圆形头像。旁边是名字 `G045` 和一朵极其微小的“锁”形能量符文（暗示不可修改/删除）。* **Bios**：一行极细的灰色斜体签名。* **✨ 记忆锚点展示区 (The Whispering Ribbon)**：* 在 Bios 下方，设计一条“流光记忆带”。* 视觉上是一条极细的水平轨道（像老式磁带或数据流），左右两端使用渐变遮罩（mask-image）融入背景，造成一种无尽感。* **数据展示**：记忆条目在轨道上缓慢自动向左滚动。格式为：`[ 关键词 ]` 用亮火色（#f8bf74）高亮，紧跟的 `具体内容...` 用暗火色（#a63d00）或半透明白色，并带有轻微的高斯模糊，就像是脑海中闪过的低语。* **[第二层级：Superiors (长期羁绊)]*** **布局**：两列错落的纵向玻璃卡片（或者宽横向，取决于信息量）。* **内容**：标准圆形头像，名字。同样拥有“流光记忆带”，但滚动速度和光芒亮度比 G045 稍微暗淡一点，以区分层级。* **[第三层级：Standards (无状态工具人)]*** **布局**：采用最紧凑的“玻璃切片（Chips）”流式排版。* **内容**：只有小头像和名字，没有记忆带。就像是工具箱里随时可以调用的即抛型法术卷轴。* **[底部]*** 保留全局导航栏。---### 界面二：Agent Profile（代理个人主页，L2层）**视觉氛围**：X / Ins 主页的“深渊晶体”版本。进入这个页面，全局底部导航栏消失。* **[顶部与头图区 (Header Banner)]*** **返回键**：左上角悬浮 `< Agents`。* **背景 Banner**：屏幕上半部分是一块巨大的、极低透明度的毛玻璃。根据
